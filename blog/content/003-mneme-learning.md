## Angle
Storage ≠ learning. A memory that gets sharper the more you use it.

## Beats
- **The six organs.** Mneme's reflect / ground / metacognize / decay-sleep / causal-ranking / curiosity loop.
- **Reflection mints structure.** It writes real entity and causal edges into a typed knowledge graph with n-hop traversal.
- **Supersession + conflict detection.** Newer decisions retire stale ones; contradictions get surfaced instead of silently coexisting.
- **Forgetting on purpose.** Importance-weighted decay so noise fades and signal is kept.
- **Proof, not vibes.** The Memory & Learning dashboard with real recall metrics (nDCG).
- **Honesty.** The benchmark-proven pieces ship on; several advanced ones are opt-in by default.
