# The Weave (v1.23) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, autonomous). Steps use checkbox (`- [ ]`) syntax. Spec: `docs/superpowers/specs/2026-07-09-the-weave-cognitive-fabric-design.md`.

**Goal:** Ship a self-weaving cognitive fabric — memory↔code bridge, background connection-miner, issue→location prediction, rock-solid cross-repo memory, upgraded learning — as v1.23.0.

**Architecture:** Extend (not replace) the existing memory brain + code graph, join them with a structured code anchor, and add a background miner that materializes bridge + cross-repo analogy edges ahead of time. Everything local-first, append-only JSONL, native-free.

**Tech Stack:** Electron main (TypeScript), Vitest (v8 coverage), existing local WASM embedder + web-tree-sitter, node-pty. No new runtime deps.

## Global Constraints

- **No new runtime dependencies.** Reuse local embedder (`localEmbedder.ts`) + tree-sitter WASM only.
- **Native-free, local-first, append-only JSONL** persistence; atomic tmp+fsync+rename for rewrites.
- **Back-compat:** every new field optional; old data works unchanged; migrations one-time + lazy.
- **Coverage gate (CI):** lines ≥90, stmts/fn ≥89, branches ≥84 floor — keep **branches ≥85 with margin**. Run CI-style coverage (hide `resources/models/bge-small-en-v1.5` + `node_modules/@huggingface/transformers/.cache/Xenova/bge-small-en-v1.5`; `npm run grammars`) before each push.
- **Commit convention:** direct to `main`, no branches/PRs. `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`. Push only green checkpoints.
- **Release:** bump `package.json` to `1.23.0`, push `v1.23.0` tag, watch BOTH Tests + Release to green via `--json conclusion`, confirm 15 assets + release email.
- **Every new branch gets a unit test.** TDD: failing test → verify fail → implement → verify pass → commit.
