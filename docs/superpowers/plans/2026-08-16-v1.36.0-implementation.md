# v1.36.0 Implementation Plan — Strategic Surfaces A–D + Cross-Agent Memory

> Derived from `2026-08-11-strategic-surfaces-roadmap.md` after a verified 8-agent recon pass on 2026-08-16.
> Baseline v1.35.1, 8630 unit tests green, 443 files. Branch: `main` direct, no PRs.
> Coverage gate: lines 97 / fn 96 / branches 95 / stmts 96 — never lower.

## Decisions taken (these close the roadmap's two open questions)

**A1 vs A2 → neither. Ship A1.5.** A hidden `BrowserWindow` buys nothing: the MCP handlers already
null-check the window, so tools work windowless. The only thing a renderer would add is
`aiProfiles.ts launchAgentProfile` — timing-based typing into a shell PTY — which is precisely what
must *not* drive a CI run. A full Node extraction (A2) is also unnecessary: of 140 `.ts` files under
`src/main`, only 12 import `electron` and only `index.ts` is genuinely coupled. So: a **second
Electron main entry that never creates a window**, sharing a new `bootCore()` with the desktop app.

**B1 verdict → partially wired, not absent.** `recordOutcome` (`mnemeCompetence.ts:75`) *is* called
from three production paths, and `deriveOutcome` (`outcomeSignals.ts:28`) does produce records. The
failure is coverage: the wired paths are the three lowest-traffic surfaces in the app, plus one
genuine one-line hole at `index.ts:2403`. This is a day, not a week — the roadmap's worst case is off.

## Wave 3 — A: headless with the moat attached

1. `bootCore()` — lift the ~700-line `app.whenReady()` closure (`index.ts:2523-3311`) into a reusable core.
2. `registerIpc(ipc, core, getWindow)` — the 147 module-top-level `ipcMain` registrations become injectable, following the pattern `workflow/ipc.ts:77` already uses.
3. `src/main/headless.ts` as a fourth electron-vite input; `Termpolis.exe --headless <verb>`.
4. **Instance-lock blocker:** `index.ts:2507` calls `app.quit()` when the lock is held — a headless run beside the open desktop app dies silently. Headless takes a distinct lock or skips it.
5. `src/main/agentLaunch.ts` — main-owned launcher carrying model flag, primer, and proxy env (today those three facts are split across three layers).
6. `termpolis run` in the CLI. Also fix the hardcoded `PORT = 9315` — the server falls back to 9316-9319 and `stdio-adapter.cjs` already reads the `mcp-port` file; the CLI does not.
7. Increment 2: prime from shared memory, write the outcome back. Increment 3 + **C1**: secret scan fails closed, egress guard armed, audit entry written.

## Wave 4 — Cross-agent memory (explicit ask) + B3/B4

Codex today gets **the same content through a strictly weaker channel**: `memory_primer` is
vendor-neutral and Codex conversations do reach the brain, but there is no SessionStart-hook
equivalent, no `--append-system-prompt-file` (gated on `isClaude`), no `AGENTS.md` anywhere in the
repo, no `mcp__termpolis__*` auto-allow, and no live transcript watcher. Priming rests on
`buildPrimerPointer` — a request, not a delivery. Close all five.

B3 fourth vendor: **GitHub Copilot CLI** — the only candidate that closes both halves (JSONL under
`~/.copilot/session-state/` fits `tailFile`; `~/.copilot/mcp-config.json` + `~/.copilot/hooks/` +
`copilot-instructions.md` give a real priming surface). B4: e2e gate that writes as one vendor and
reads back as another.

## Wave 5 — Compression: more bang per token

Ranked by measured spend on this install (112,099 requests):

- **(a) System prompt + tool schemas are invisible to every layer** — `rewriteMessagesBody` walks only `obj.messages`. They sit at the front of the prefix and drive `cacheCreationTokens` = 258M tokens ≈ 27% of effective input spend. Measure first (`sysChars`/`toolsChars` in `WireStats`), then trim. No cache risk if changed between launches.
- **(b) Output tokens: 119.8M, entirely uncompressed** — roughly a third of the bill at 5× output pricing. `outputSteering` is on by default and nothing measures what it earns. Instrument it.
- **(c) Floor discrepancy:** `floorTokens` never reaches the wire — all four modes share a hard-coded 400-char gate (`wireCompress.ts:182/265/277`). 3,720 of 6,019 floor-eligible requests (61.8%) land under the 50% floor. Add `floorChars` to `WireWindow`, resolve once at launch, escalate-only.
- **(d) Image downscale before re-encode** — 36.8% saved today at deliberately high JPEG quality; downscaling to the model's maximum useful long edge discards bytes the API discards anyway.

## OUTCOME — what shipped in v1.36.0, and what did not

### Shipped

- **Wave 1** — correctness fixes and the compression contract.
- **Wave 2** — B1/B2 outcome loop.
- **Wave 4 (partial)** — cross-agent memory reaches a plain shell: `termpolis-cli`
  gained `primer` / `recall` / `remember`, and its long-standing hardcoded-9315 bug
  is fixed (it now reads `mcp-port` exactly as `stdio-adapter.cjs` always has).
- **Wave 5** — floor wiring (c), image downscale (d), and prefix-head instrumentation.

### The prefix head is now measured, and it is the honest answer to "why not more?"

Wave 5(a)/(b) collapsed into one code path: reading `system` for size and reading it
for the steering marker is the same pass, so `measurePrefixHead()` closes both gaps.
It is measured *before* the round-trip guard, because a request we decline to compress
still costs money — those were exactly the requests whose cost was invisible.

The head — system prompt plus tool schemas — is what every request re-sends and what a
cache write is billed 1.25x for. No compression layer touches it. The receipt now says so
out loud, next to the savings, including how much of it is Termpolis's own tools.

### Deferred — and why each one is a deferral rather than a miss

**Wave 3, headless boot (and Workstream C, which depends on it).** Headless needs a
~700-line `app.whenReady()` closure lifted into a `bootCore()` and 147 module-top-level
`ipcMain` registrations made injectable. That is the single highest-risk refactor available
in this codebase, and the brief for this release was "rock solid enterprise ready."
Shipping it half-verified would trade a real regression for a checkbox. The bounded,
testable part of the same goal — giving a shell, a CI job, or a git hook reach into the
shared brain — shipped instead, as the three `termpolis-cli` memory verbs.

**B3, the GitHub Copilot CLI watcher.** A fourth vendor touches 10+ union sites
(`AgentType`, `DetectedAgent`, `ConversationSource`, `SecondOpinionAgent`, `AgentTarget`,
the workflow `AgentRunSpec`, two renderer components). A watcher without the matching
`ConversationSource` backfill is half-done cross-agent ingestion, which is worse than a
clean deferral: it would show Copilot in the UI while its history stayed invisible to memory.

**B4, the handoff e2e gate.** Depends on B3.

**The 1-hour cache TTL.** `ttl: '1h'` needs the `extended-cache-ttl-2025-04-11` beta
header — a 400 on any account without it — and it is a net *loss* on dense sessions: a
1h write costs 2x versus 1.25x, so it only pays above roughly 1.6 cache expiries per hour.
Shipping it blind would have raised bills for the heaviest users. It is now
measurement-gated by the instrumentation this release adds, which is the point of adding it.

**Trimming Termpolis's own tool schemas.** Measured, then deliberately not cut: 34 tools,
18,081 chars, ~4,500 tokens per request, ~1% of the effective bill. Those descriptions are
what make Claude and Codex actually reach for the memory tools. "I don't want memory
sacrificed either" — so the deliverable here is the measurement, not the cut.
